# Spec Resistance — Companion Explorer

Interactive companion for the paper *"Large language models that perfectly evaluate products systematically refuse to recommend the best one"*.

- 627,491 trials
- 30 frontier LLMs across 7 providers
- 34 assortments × 20 categories
- 32 experimental conditions
- 19 OpenAI fine-tuned models (causal mechanism panels)
- 4 pre-registered human studies (N = 3,164)

Live: https://felipemaffonso.github.io/spec-resistance-companion/

This is the built artifact. The source lives at `projects/spec-resistance-companion/` in the academic-research workspace.
